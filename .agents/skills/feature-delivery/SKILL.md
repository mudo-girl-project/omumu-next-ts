# Purpose

Deliver one approved feature with evidence.

## Use When

- A task changes approved behavior.

## Do Not Use When

- The request is investigation-only or review-only.

## Required Inputs

- Active task and acceptance criteria.

## Workflow

1. Read instructions and tests.
2. Confirm scope.
3. Verify behavior before completion.

## Guardrails and Stop Conditions

- Stop for conflicting contracts or missing acceptance criteria.

## Required Artifacts

- Changed files and evidence.

## Verification

- Run focused required checks.

## Completion Report

- List changes, checks, and residual risk.
