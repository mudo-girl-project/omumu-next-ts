# Purpose

Explain a selected change using evidence.

## Use When

- A user asks to understand one change.

## Do Not Use When

- The request collects personal activity or work logs.

## Required Inputs

- Change unit and evidence link.

## Workflow

1. Select one change.
2. Ask recall questions.
3. Explain linked concepts.

## Guardrails and Stop Conditions

- Do not auto-confirm user understanding.

## Required Artifacts

- Evidence, questions, and explanation.

## Verification

- Tie concepts to actual evidence.

## Completion Report

- State the explanation and open question.
